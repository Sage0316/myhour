# 하꾸 Product Brand

## Canonical Naming

- **Korean product name**: 하꾸
- **Latin product name**: hakku
- **Name origin**: 하루 꾸미기
- **Repository identifier**: `Sage0316/myhour`
- **Current source directory and legacy deployment base**: `myhour`

## Usage Rules

1. 사용자에게 보이는 앱 이름, PWA 설치 이름, 문서 제목과 제품 안내에는 `하꾸`를 사용한다.
2. 영문 또는 기술적으로 라틴 문자만 허용되는 제품 표기에는 `hakku`를 사용한다.
3. 첫 소개에서는 `하꾸 (hakku, 하루 꾸미기)`로 의미를 함께 설명할 수 있다.
4. 저장소 주소, 소스 디렉터리, 기존 배포 경로는 별도 변경 결정 전까지 `myhour`를 유지한다.
5. 내부 패키지명, URL과 데이터 키를 제품명과 동시에 강제로 변경하지 않는다. 마이그레이션과 호환성 검토 후 별도 변경한다.

## Launch Copy Foundation

- **One-line description**: 하루의 순간을 가볍게 기록하고, 나만의 하루 영상으로 꾸미는 로컬 우선 저널.
- **Short positioning**: 기록은 짧게, 하루는 오래.
- **Core promise**: 사용자가 순간만 남기면 하꾸가 안전하게 모아 하루의 이야기로 정리한다.
