# U7 NFR Design Patterns

- Build once and promote immutable artifact digests.
- Protected branch and required checks enforce quality gates.
- Preview and production use separate identities, secrets, state namespaces, and origins.
- Pinned actions, lockfile, scans, and SBOM reduce supply-chain risk.
- Security headers are tested against deployed responses.
- Safe telemetry drives auth, limit, AI, and Push alerts.
- Last-known-good promotion provides deterministic rollback.
- Documentation-as-gate keeps privacy and actual behavior aligned.
