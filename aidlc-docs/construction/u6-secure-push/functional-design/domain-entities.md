# U6 Domain Entities

| Entity | Purpose |
|---|---|
| PushPreferences | Interval, timing, time zone, and session bounds |
| PushSchedule | Installation, version, normalized preferences, active status |
| PushSubscriptionRecord | Owned browser subscription and endpoint host class |
| PlannedDelivery | Slot, kind, scheduled instant, payload metadata |
| DeliveryKey | Idempotency identity |
| DeliveryState | Reserved, sent, retryable, permanent failure |
