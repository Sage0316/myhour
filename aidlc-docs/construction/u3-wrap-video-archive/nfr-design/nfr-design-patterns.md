# U3 NFR Design Patterns

- Capability negotiation selects supported codec and profile before work.
- Mobile-default profile bounds dimensions, frame rate, bitrate, and memory.
- Phase-based progress and cooperative cancellation keep control responsive.
- Resource leases close canvas streams, audio nodes, tracks, timers, and URLs.
- Commit-last keeps source data immutable until output is durable.
- Stable archive-ID navigation removes transient-state coupling.
- Accessible state machine manages dialog focus, live progress, and errors.
