# U3 Business Rules

| Rule | Definition |
|---|---|
| U3-BR-01 | Visible wrap controls must change output or schedule behavior. |
| U3-BR-02 | Default output is 720x1280 with a conservative mobile profile. |
| U3-BR-03 | Capability and storage preflight occurs before rendering. |
| U3-BR-04 | Progress phases are prepare, encode, write, and commit. |
| U3-BR-05 | Failure or cancellation cannot delete source media or prior archives. |
| U3-BR-06 | Archive navigation uses stable `ArchiveId`, never an ephemeral Object URL. |
| U3-BR-07 | Object URLs, streams, timers, and audio resources close on every terminal path. |
| U3-BR-08 | Required actions have semantic controls and are not long-press-only. |
