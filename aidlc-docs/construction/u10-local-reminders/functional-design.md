# U10 기록 시간 알림(폰 예약 알림) — 기능 설계

## 목표
iOS 앱에서는 알림 서버 없이 폰 자체 예약 알림으로 기록 시간을 알린다. 웹 버전은 종료 전까지 기존 웹 푸시를 그대로 쓴다.

## 규칙
| 규칙 | 내용 |
|---|---|
| 하루(세션) | 설정의 시작 시간부터 다음 날 시작 시간 전까지. 시작 시간보다 이른 슬롯은 다음 날짜의 그 시각 |
| 슬롯 | `generateSlots(settings)`와 같은 목록 (시작·간격·종료 방식) |
| 알림 시점 | `before`=슬롯 1분 전, `exact`=슬롯 정각, `both`=둘 다 |
| 문구 | 정각 "지금 이 순간을 기록해볼까요? 📸", 1분 전 "1분 뒤 기록 시간이에요 ✏️", 제목 "하꾸" |
| 기간 | 오늘 포함 3일분 |
| 개수 | 최대 60개 (iOS 앱당 예약 한도 64개) |
| 지난 시각 | 지금보다 이전은 걸지 않음 |
| 마감한 날 | 이미 마감한 하루의 남은 알림은 걸지 않음 |
| 다시 걸기 | 앱 시작, 앱이 다시 앞으로 나올 때, 설정 변경, 하루 마감 때 기존 예약을 모두 지우고 다시 계산 |
| 켜기·끄기 | 설정의 "기록 시간 알림" 스위치. 켤 때 권한 요청, 거절이면 아이폰 설정 안내 |

## 구성
- `src/notifications/reminderPlan.ts` — 순수 계산 함수 `planReminders` (테스트 대상)
- `src/notifications/localReminders.ts` — Capacitor Local Notifications 감싸기 (권한, 예약, 취소)
- `App.tsx` — 설정·마감 상태가 바뀌거나 앱이 다시 보일 때 다시 걸기
- `SettingsScreen.tsx` — 앱이면 예약 알림, 웹이면 웹 푸시

## 검증
- 단위 테스트: 정각·1분 전·둘 다, 자정 넘는 슬롯, 마감한 날 건너뛰기, 속성 테스트(한도·미래·정렬·고유 ID)
- 실제 알림 표시는 TestFlight 기기에서 확인 (U15 이후)
