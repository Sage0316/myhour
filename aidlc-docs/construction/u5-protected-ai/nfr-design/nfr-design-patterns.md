# U5 NFR Design Patterns

- Data-minimization mapper constructs a strict outbound DTO.
- Non-extractable install key and canonical signed request establish ownership.
- Timestamp, nonce, audience, and body hash reduce replay and substitution.
- Layered validation applies origin, body, schema, auth, quota, and model policy.
- Timeout and bulkhead isolate provider latency.
- Local fallback guarantees optional AI cannot block wrap-up.
- Safe logging and installation pseudonymization protect content.
