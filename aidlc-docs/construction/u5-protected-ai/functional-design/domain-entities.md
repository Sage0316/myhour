# U5 Domain Entities

| Entity | Purpose |
|---|---|
| AIConsentState | Notice version, decision, and decision time |
| InstallationIdentity | Installation ID and non-extractable signing key reference |
| AIDirectionRequest | Minimal versioned text and caption DTO |
| SignedRequestMetadata | Audience, time, nonce, body hash, signature |
| DirectorMetadata | Validated title, mood, scenes, and music hint |
| AIUsageDecision | Allowed, denied, retry-after, and remaining quota bucket |
