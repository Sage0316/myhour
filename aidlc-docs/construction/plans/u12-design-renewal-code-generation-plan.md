# U12 디자인 리뉴얼 — 코드 생성 계획

실행 계획(`inception/plans/execution-plan.md`) 승인으로 계획 승인을 갈음한 단위다. 기능과 화면 순서는 그대로 두고 디자인만 바꾼다.

## 기준
- 캔버스 시안(홈, 오늘, 기록하기 5종, 하루 마감, 아카이브, 설정)과 대화에서 확정한 결정
  - 하단 탭 4개(홈·오늘·아카이브·설정) 유지, 아이콘 추가
  - 본문은 기기 기본 고딕, 손글씨(Gaegu)는 날짜·테이프 라벨에만
  - 두꺼운 오프셋 그림자 없이 얇은 잉크 테두리
  - "조각" 대신 "기록" 용어
  - 칸 너비·끝 정렬이 어긋나지 않게
- `TYPE_COLORS`는 영상 렌더링에도 쓰이므로 바꾸지 않고, 화면 쪽 바탕색만 종이 톤으로 따로 둔다

## 단계
- [x] 공통 디자인 값 `src/design.ts` (색, 글꼴, 종이 배경, 테이프, 카드, 버튼)
- [x] Gaegu 글꼴을 `@fontsource/gaegu`로 앱에 포함 (외부 글꼴 서버 요청 없음), 라이선스 고지 추가
- [x] 전역 스타일: 종이 배경, 본문 글꼴, 포커스 색, 한국어 단어 단위 줄바꿈
- [x] 하단 탭바 (아이콘, 선택 탭 노란 스티커)
- [x] 홈: 별 테이프 타임라인, 폴라로이드 썸네일, 첫 기록 전 창 스티커, "다음 기록까지" 표시
- [x] 오늘: 같은 크기 카드, 시간 테이프, 삭제 시트
- [x] 기록하기: 모드 탭, 폴라로이드 촬영 카드 + 앨범 줄 버튼, 영상(뷰파인더), 음성, 글(줄노트 두 줄 + 영상 미리보기), 문구 남기기
- [x] 하루 마감: 구조 유지, AI 촬영감독 연출 노트, 별밤 영상 버튼
- [x] 아카이브: 폴라로이드 카드 + 날짜 테이프, 상세 시트, 전체 화면 영상
- [x] 설정: 형광펜 소제목, 카드, 스위치, 고정값 행 끝 정렬
- [x] 검증: `pnpm check`(lint, 단위 테스트 72개, Worker 테스트, 빌드), Playwright e2e 2개(접근성 axe critical 포함), 화면별 390px 캡처 확인
