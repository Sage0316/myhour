# U14 출시용 정리 — 코드 생성 계획

## 목표
앱스토어 앱에 숨은 개발 기능이나 개발자용 문구가 남지 않게 한다 (심사 가이드라인 2.3.1 숨은 기능 위험 제거).

## 단계
- [x] 테스트 도구(버전 7번 두드리기 → 오늘 마감 잠금 풀기)를 앱 빌드(`--mode app`)에서 제외
  - `import.meta.env.MODE !== 'app'`일 때만 열림 → 앱 번들에서는 코드째 빠짐 (빌드 결과에서 "테스트 도구" 문자열 0건 확인)
  - 웹 버전에서는 지금처럼 개발 확인용으로 남김 (웹 버전은 U16에서 종료)
- [x] 설정 화면 개발자 문구 → 사용자 문구
  - "알림 서버 배포 후 사용할 수 있어요 (준비 완료)" → "지금은 알림을 쓸 수 없어요"
  - "서버 연결 전이에요" → "지금은 AI 연출을 쓸 수 없어요"
  - 데이터 내보내기/가져오기 설명, 가져오기 확인창을 쉬운 말로
- [x] 앱 번들에서 웹 전용 파일 제외: `bgm.html`(BGM 시청 페이지), `_headers`(GitHub Pages 설정)
- [x] pnpm check, e2e 통과
